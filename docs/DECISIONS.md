# Decisions log

Answers locked in session of 2026-08-19. Supersedes anything conflicting in `PLAN.md`.

| # | Decision | Consequence |
|---|---|---|
| D1 | **Art is procedural first.** Face art generated in Canvas 2D from landmark anchors; Siva draws real SVGs later and swaps them in via `content/art-registry.ts`. | P3 is not blocked on assets. Registry must accept both a procedural generator and an SVG texture for every art slot, behind one interface. |
| D2 | **Ship as a reusable package.** Engine is framework-agnostic; React is a thin wrapper. | `src/engine/**` has zero React imports (lint-enforced). Public surface is one `createExperience()` factory + a `<ThereYouAre />` React wrapper. Next.js migration = folder move. |
| D3 | **Identity proposed by me.** Near-black ground, charcoal surface, graphite, warm paper, electric blue, one warm accent. Self-hostable typefaces only. | `styles/tokens.css` is the single source; every colour/space/type value is a token. No hardcoded hex anywhere else. |
| D4 | **Conservative pins.** Vite 7.3.6, TypeScript 5.9.3, not Vite 8 / TS 7. | Verified: `@vitejs/plugin-react@6` hard-requires `vite ^8`, so the React plugin pins to `5.2.0`. Vitest 4.1.11 supports Vite 7. ESLint 10 + typescript-eslint 8.67 are compatible. |
| D5 | **Both aspect ratios in parallel from P1.** 3:2 desktop and 4:5 mobile tuned together. | Every visual change gets checked in both crops before it counts as done. `viewport.ts` tests cover both from the start. |
| D6 | **No-camera fallback is a real recorded loop of Siva** — recorded *from the finished renderer itself*, not a screen capture, before launch. | Build a dev-only `?record=1` mode: `canvas.captureStream()` → `MediaRecorder` → webm download. Interim fallback until that recording exists = static poster frame. Fallback video is lazy-loaded, muted, `playsInline`, loops, and never downloads on the camera-granted path. |
| D7 | **All four art modes at MVP** — graphite, sunny, dream, marker. **Random per page load**, then fixed for that visit, **plus a small in-frame style picker** once the camera is live. | Viable only because art is procedural (D1): a mode is a *parameter set* (palette, stroke width/jitter/texture, glow, grain), not four hand-drawn asset sets. Modes live in `content/art-modes.ts`. Randomness gives repeat visitors something new; the picker means nobody is stuck with the one they like least, and it turns the four modes from a hidden detail into a visible feature. Picker is 4 small marks inside the frame edge, keyboard-reachable, hidden until `live`. Quality bar must hold in all four before launch. |
| D8 | **Capture = PNG download + Web Share API** where supported. | Share sheet on mobile; silent fallback to download elsewhere. No clipboard write at MVP. |
| D9 | **Signature: `You by Siva Serafino · 2026`** | Year is a constant in `content/copy.ts`, not `new Date()` — the poster should say the year it was made, and a hardcoded value is auditable. Set small, ~0.85 opacity, ~-2°. |
| D10 | **Poster = matted print.** Photo inset, asymmetric paper margin, signature lower-left in the margin. | Capture layout is its own module (`capture/poster-layout.ts`) and does *not* reuse the live aperture layout — different composition, same transform math. |
| D11 | **Blueprint copy kept verbatim** (§81). | All strings in `content/copy.ts`. Components never contain literal copy. |
| D12 | **Hosting: GitHub Pages**, via a build-and-deploy Action on push to `main`. | Free, HTTPS by default (required for the camera), no account sprawl. Consequences: (a) Pages cannot set custom response headers, so `Permissions-Policy: camera=(self)` cannot be sent — harmless, because `self` is already the browser default for camera, and the `_headers`/`vercel.json` files stay in the repo for a future move; (b) no SPA routing, so the workflow copies `index.html` to `404.html`; (c) the site lives at `/<repo>/`, so `BASE_PATH` is set at build time and a custom domain later is one repo variable. **Open risk (measure at P2):** GitHub Pages may serve `.wasm` uncompressed — 12MB instead of 3.4MB gzipped. If the measured first-load is bad, move to Cloudflare Pages, which brotli-compresses wasm. Both header files are already committed for that. |
| D13 | **No analytics. One anonymous counter instead.** Single increment per browser on `experience_started` (and `portrait_saved`), to a Cloudflare Worker we own. | No third-party script, no cookies, no IP/UA/timestamp stored — two integers in KV. Off unless `VITE_COUNT_ENDPOINT` is set, so dev sends nothing. `?nocount=1` excludes Siva's own visits. Forces a copy change: the blanket "nothing is uploaded" becomes two precise lines (`intro.privacy` + `intro.privacyNote`). Setup in [`COUNTER.md`](./COUNTER.md). |
| D14 | **Camera stops when the tab is hidden**, resumes on return. | Tracks stopped after 30s hidden — the camera light must not linger while someone is in another tab. Timer, not immediate, so a quick tab-switch does not force a re-acquire flash. Implemented in `engine/camera` at P1. |
